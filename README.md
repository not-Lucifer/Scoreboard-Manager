# Scoreboard Manager

Full stack app to manage teams, matches and live scores.

## Tech
- Frontend: React + Vite
- Backend: coming soon

## Run frontend
```
cd frontend
npm install
npm run dev
```

## Pages
- Home - live matches
- Teams - add / delete teams, team details with players
- Matches - create match, open scoreboard
- Scoreboard - start match, update score, end match
- Leaderboard - points table (win 3, draw 1)
- Login / Register - forms only for now
